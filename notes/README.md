# notes — 강의 정리 폴더

날짜별로 파일 1개. 녹화본·자료는 `assets/<날짜>/`에 같이 둔다.

| 날짜 | 주제 | 상태 | 앱 반영 |
|---|---|---|---|
| 2026-09-07 | [구강간호](2026-09-07-구강간호.md) | 아이디어만 (강의 내용 대기) | ⬜ |

## 파일 규칙
- 노트: `notes/YYYY-MM-DD-주제.md`
- 자료: `notes/assets/YYYY-MM-DD/` (녹화본, 슬라이드, 필기)
- 노트 안 순서: 요약 → 강의 내용 → 내 아이디어 → 근거 검토 → 앱 반영 → 할 일
- 앱(`index.html`) 반영이 끝나면 위 표의 "앱 반영"을 ✅로
