## ④ 아이디어 검토 — 짧은 버전

**1) 치아 사정을 구강간호에 넣는 것 → 넣는 게 맞다.**
칫솔질이 병원획득폐렴(HAP)·ICU 사망률·인공호흡기 기간·ICU 재원일을 유의하게 줄인다는 메타분석이 있다
(PubMed: Ehrenzeller & Klompas, *JAMA Intern Med* 2024 — HAP RR 0.67, ICU 사망 RR 0.81).
즉 **"칫솔질을 한다"가 표준이면, "이 환자 입에 칫솔질을 해도 되는 치아 상태인가"를 먼저 보는 게 논리적으로 앞선다.**
흔들리는 치아·보철물은 칫솔질·흡인·bite block·재삽관에서 탈락 → **기도 이물 = 응급**이 되기 때문.

**2) 치아손상 프로토콜 → "마취/기도관리"에는 있고, "ICU 일상 구강간호"에는 사실상 없다.**
프랑스 마취과 가이드라인(2012)이 술전 치아 사정·설명·동의·손상 시 대응까지 권고하고 있고,
탈락치 회수 실패 사례보고도 최근 나와 있다(Cureus 2026).
하지만 이건 **삽관 시점 한 번**의 이야기고, **ICU 입실 후 매일 하는 구강간호 맥락의 치아 프로토콜은 표준화가 약하다.**
→ 그 틈이 이 아이디어의 가치. "없어서 못 하는 것"이 아니라 **"아직 아무도 안 만들어놔서 만들 수 있는 것"**.

**3) 신경계 중환자실이면 특히 명분이 선다.** 발작(이악물기), 의식저하, 편마비, 삼킴장애 —
치아 손상 위험과 흡인 위험이 동시에 높은 집단.

## ⑤ 아이디어 검토 — 상세 버전

### 5-1. 왜 치아 사정이 구강간호의 앞단에 와야 하나

| 근거 | 내용 | 출처 |
|---|---|---|
| 칫솔질 효과 | 15 RCT, 10,742명. HAP RR 0.67 (0.56–0.81), ICU 사망 RR 0.81 (0.69–0.95), MV −1.24일, ICU LOS −1.78일. 인공호흡 환자에서 특히 유의. 하루 2회로 충분 (더 자주 해도 추가 이득 없음) | PubMed / JAMA Intern Med 2024, [DOI](https://doi.org/10.1001/jamainternmed.2023.6638) |
| 치아손상 위험인자 | ① **기존 치아상태 불량**, ② 어려운 후두경/삽관. 마취 관련 배상청구 1위가 치아손상 | PubMed / Ann Fr Anesth Reanim 2012, [DOI](https://doi.org/10.1016/j.annfar.2012.01.004) |
| 탈락치 = 기도 응급 | 흔들리는 치아 다수 환자, 후두경 중 상악 중절치 파절 + 측절치 탈락. **흉부 X선에 안 보였고** 재탐색 끝에 pyriform fossa에서 Magill 겸자로 회수 | PubMed / Cureus 2026, [DOI](https://doi.org/10.7759/cureus.110325) |

논리 연결:
1. 칫솔질은 이제 "해도 되는 것"이 아니라 **해야 하는 것**이다 (근거 강함).
2. 그런데 칫솔질·흡인·bite block·재삽관은 전부 **치아에 물리력이 가해지는 행위**다.
3. 그러면 구강간호 프로토콜은 반드시 **"치아 사정 → 위험 등급 → 그에 맞는 구강간호 강도"** 순서를 가져야 한다.
4. 현재 대부분의 VAP 번들은 "chlorhexidine / 칫솔질 q12h" 같은 **행위만** 있고 **치아 상태 분기(branch)가 없다.** ← 여기가 빈틈

### 5-2. 사정 도구 후보 (※ 실제 채택 전 타당도 근거 재확인 필요)

- **OHAT** (Oral Health Assessment Tool) — 8개 항목(입술·혀·잇몸·타액·자연치아·의치·구강청결·치통), 0/1/2 점수. 의존도 높은 환자용으로 널리 쓰임
- **BOAS** (Beck Oral Assessment Scale) — 입술·점막·혀·잇몸·치아, 중환자 대상 문헌 다수
- **THROAT** — 인공호흡 환자용으로 개발된 도구

→ 우리가 추가하려는 건 이 도구들에 대부분 있는 "치아(teeth)" 항목을
**"청결도"가 아니라 "구조적 안정성(흔들림·파절·보철)"으로 확장**하는 것. *이게 아이디어의 핵심 차별점.*

### 5-3. 제안 — 치아 사정 항목 (입실 시 1회 + 매 duty 간단 확인)

| 구분 | 확인 항목 | 기록 방식 |
|---|---|---|
| 구조 | 결손치 위치, 잔존치 수 | 치식 도표에 표시 |
| 동요도 | 흔들리는 치아 (Miller I~III) | 위치 + 등급 |
| 파절 | 기존 파절·치관 결손 | 위치 + 사진 |
| 보철 | 크라운/브릿지/임플란트/**틀니(부분·전체)** | 유무 + 제거 여부 |
| 치주 | 잇몸 출혈·부종·농 | 있음/없음 |
| 위험행위 | bite block, 이악물기, 재삽관 예정, 발작 위험 | 체크 |

**위험등급 예시**
- 🟢 저위험: 동요도 없음, 보철 안정 → 표준 칫솔질 q12h
- 🟡 중위험: 동요도 I, 다수 결손, 치주염 → soft brush + 압력 낮춤, 매 duty 재확인
- 🔴 고위험: 동요도 II~III, 발작/이악물기, 어려운 기도 → **칫솔질 대신 스펀지/흡인칫솔 + 치과 협진 + 삽관·발관 전 팀 공유**

### 5-4. 제안 — 치아손상 발생 시 대응 프로토콜 초안

1. **중단 & 기도 확보** — 조작 즉시 중단, 흡인, SpO₂ 확인
2. **치아/파편 회수 확인** — 몇 개, 어느 치아, 회수됐는지. *회수 못 하면 사라진 게 아니라 어딘가 있다고 가정*
3. **영상** — 경부~흉부 포함 촬영. **X선 음성이 배제가 아님** (Cureus 사례) → 후두·pyriform fossa 재탐색, 필요 시 기관지내시경
4. **보존** — 회수한 치아는 건조 금지. 생리식염수/우유/HBSS에 보관, 치근 만지지 않기
5. **협진** — 치과/구강외과 응급 협진, 재식립 가능성 판단은 시간 싸움
6. **기록·설명** — 시점·상황·시술자·조치, 보호자 설명. (마취 영역에선 이 문서화가 배상청구 방어의 핵심)
7. **재발 방지** — 다음 기도조작 전 팀 브리핑에 "치아 고위험" 플래그

### 5-5. 신경계 중환자 특이 포인트 (이 앱 맥락과 연결)

- **발작**: 이악물기 → 치아 파절·설열상. *발작 중 입에 무엇도 넣지 않는다*는 원칙과 충돌하지 않게 문구 설계 필요
- **의식저하/GCS 저하**: 자가 구강관리 불가 + 삼킴반사 저하 → 구강 세균의 하기도 흡인
- **뇌졸중 편마비/편측무시**: 마비측 협부에 잔사 저류 → 편측 집중 사정
- **삼킴장애**: 세척액 흡인 위험 → 흡인칫솔·최소 수분
- **긴 재원 + 기관절개 전환**: 장기 구강 방치 구간이 실제로 여기서 생김

## ⑤-2 추가 아이디어 검토 — 상세 버전

### A. 출혈 위험 — "주의"를 규칙으로 바꾸기

문제: "출혈 조심하세요"는 지시가 아니라 감정이다. 사람마다 다르게 한다. → **수치와 시간으로 분기**시켜야 함.

**분기 기준 초안 (병원 지침과 대조 후 확정)**

| 상황 | 분기 |
|---|---|
| IV 혈전용해(tPA) 후 24시간 | 침습적 처치 최소화 구간. 칫솔질 보류 → 스펀지·흡인 위주, 24h 후 재평가 |
| 혈소판 감소 | 기관 기준 확인 후 임계값 설정 (예: 저하 시 초극세모 다운그레이드, 더 낮으면 스펀지). **수치 기준은 우리 병원 지침 확인 필요** |
| DOAC/와파린·이중 항혈소판 | 칫솔질 유지하되 압력 낮춤 + 출혈 시 압박·기록 |
| 활동성 잇몸 출혈 | 압박 → 지혈 확인 → 다음 회차 강도 하향 + 치과 협진 |
| 출혈성 뇌졸중·ICP 상승 | 구역·기침 유발 최소화(Valsalva → ICP 상승). 짧게, 흡인 동시에 |

핵심 논리: **칫솔질을 "빼는" 게 아니라 "내리는" 것.** 스펀지는 플라크 제거력이 약해서 완전 중단은 폐렴 위험을 올린다 → 그래서 뒤의 차수 구조가 필요.

### B. NM blocker 없이 하는 구강간호 — 물림 손상

- 신경계 중환자는 신경학적 진찰 유지가 목적이라 진정/차단을 깊게 못 감 → **각성·저항 상태에서 구강간호**가 기본값
- 발작·이악물기·자세 이상(decerebrate)에서는 **개구 자체가 위험 행위**
- 사람 물림 손상은 구강 상재균 때문에 감염률이 높은 축에 든다 → 간호사 상해 = 실제 산업재해

**규칙 문장 (프로토콜에 그대로 넣을 것)**
1. **환자 입안에 손가락을 넣지 않는다.** 벌리는 것은 항상 도구로 한다
2. 저항·이악물기 환자는 **2인 1조** (1인 도구·시야, 1인 칫솔·흡인)
3. 물림 발생 시: 즉시 이탈 → 흐르는 물 세척 → 상처 평가 → **감염관리·산업보건 보고** → 항생제 예방 필요성 판단(구강 상재균 커버) → 사건 기록
4. 개구가 안 되면 **억지로 열지 않는다.** 3차 중재(아래)로 전환

### C. 도구 — "리트렉터처럼" 아이디어 구체화

| 목적 | 도구 | 메모 |
|---|---|---|
| 개구 유지 | mouth prop / bite block (일회용 실리콘형) | 손가락 대체. **기존 bite block이 치아에 물리는 위치 확인 필요(치아 손상 ①과 연결)** |
| 협부 견인·시야 | 치경(mouth mirror), 일회용 리트랙터 | 편측무시 환자 마비측 잔사 확인에 유용 |
| 흡인 동시 | 흡인칫솔(suction toothbrush), Yankauer | 세척액 흡인 위험 낮춤 → 삼킴장애 환자 필수 |
| 광원 | 펜라이트/헤드램프 | 사정 신뢰도의 절반은 조명 |
| 시간 관리 | 사분면(quadrant)당 30초 룰 | 저항 환자에서 "짧게 여러 번"이 현실적 |

→ 아이디어의 프레임: **"손 → 도구"로 바꾸면 간호사 안전 + 사정 정확도 + 치아 보호가 동시에 올라간다.** 하나의 도구 세트로 세 문제를 푼다는 게 설득 포인트.

### D. ⭐ 차수별 중재 프로토콜 (이 정리의 핵심 뼈대)

두 축으로 짠다.

**축 1 — 강도 차수 (무엇을 할지)**

| 차수 | 대상 | 중재 |
|---|---|---|
| **1차 (표준)** | 출혈·물림·치아 위험 모두 낮음 | 칫솔질 q12h(soft, 흡인칫솔), 최소 수분 + 흡인 병행, 입술 보습, 치아 daily 확인 |
| **2차 (조정)** | 출혈 위험 / 개구 곤란 / 치아 동요 중 **1개 이상** | 초극세모·소두 칫솔로 다운그레이드, 압력↓, mouth prop + 2인 1조, 사분면 30초로 분할, 매 duty 재사정 |
| **3차 (보류·대체)** | tPA 24h 이내 / 활동성 출혈 / 개구 불가 / 동요도 II~III | 칫솔질 보류 → 흡인 스펀지 + **불소 도포로 우식 방어 전환**, 치과 협진, **재시도 조건을 반드시 명시** |

핵심: **3차는 "포기"가 아니라 "다른 수단으로 계속"이다.** 재시도 조건(예: tPA 24h 경과 & 출혈 없음 → 2차로 상향)을 안 적으면 환자가 3차에 방치된다. ← 기존 지침들의 실제 실패 지점

**축 2 — 시간 차수 (언제 할지)**

| 시점 | 할 일 |
|---|---|
| T0 (입실 24h 내) | 전체 구강·치아 baseline 사정, 사진, 차수 배정 |
| 매 duty | 간단 재확인(출혈·동요·개구) → **차수 상향/하향 판단** |
| 72시간 | 재평가 + 치과 협진 필요성 |
| 주 1회 | 불소 도포(대상자), 기록 정리 |
| 상태 변화 시 | 발작 후 / 재삽관 후 / 시술 후 → 즉시 재사정 |

### E. 불소 — 넣되 범위를 정확히

**왜 ICU에서 우식이 문제가 되나 (기전)**
구강호흡 + 항콜린제·이뇨제·진정제 → 타액 감소 → 완충·재광화 상실 + 탄수화물 함유 구강용액 → 장기 재원 환자에서 급속 우식. 기관절개로 전환되면 재원이 몇 주가 되므로 **"입원 중 우식"이 실재하는 문제**가 된다.

**근거 (PubMed 확인)**

| 제제 | 효과 | 근거 |
|---|---|---|
| 5% NaF 바니시 | 노인 치근우식 예방분율 **64%** | J Dent 2022 체계적고찰 |
| 1.23% APF 겔 | 예방분율 **32%** | 동일 |
| 38% SDF | 예방분율 25–71%, 치근우식 **정지율 42%**(24개월) | 동일 |
| SDF (Cochrane) | 치근우식 신생 예방 **MD −0.79면 (중등도 확실성)**. 소아 유치 관련 결과는 불확실 | Cochrane 2024 |

**우리 맥락으로 번역**
- **바니시가 ICU에 유리하다**: 소량·도포형이라 삼킴/흡인 위험이 낮고, 치과의사 없이 훈련된 간호사 도포가 현실적
- **SDF는 착색(검게 변함)** 이슈 → 중환자에선 심미보다 기능이 우선이라 오히려 쓸 수 있으나 **보호자 사전 설명 필수**
- **불소치약**은 발포·삼킴 문제 → 저포밍 소량 + 흡인 병행 원칙
- ⚠️ **위 근거는 전부 노인·의존환자 대상. ICU 직접 RCT 아님 → 외삽임을 명시하고 쓸 것.** 이걸 숨기면 프로토콜 신뢰도가 떨어짐

**3차 중재와의 연결**: 칫솔질을 못 하는 구간이야말로 불소가 가장 필요한 구간이다. → *"닦지 못하면 덮는다"* 가 3차 중재의 논리.

### F. ⭐ 흔들리는 치아를 발견했을 때 — 1차 조치 (Front-line response)

> 이게 사실상 이 프로토콜의 **엔트리 포인트**다. 대부분의 간호사가 "흔들리네?" 하고 지나가는 지점.
> 핵심 프레임: **흔들리는 치아 = 미래의 기도 이물.** 지금은 치과 문제지만, 다음 삽관 때는 기도 응급이다.

**즉시 (그 자리에서, 1분)**
1. **조작 중단** — 그 사분면 칫솔질·흡인 멈춤. 현재 진행 중인 힘부터 뺀다
2. **흡인기 확보 후 확인** — 지금 빠질 수도 있다는 전제로. 구강 내 파편·출혈 확인
3. **위치 특정** — 치식 번호로 기록(예: #11 상악 우측 중절치). "앞니"는 기록이 아님
4. **동요도 등급** — Miller I(수평 1mm 미만) / II(수평 1mm 초과) / III(수평+수직·함입)
   ⚠️ **반복해서 흔들어보지 않는다.** 검사 자체가 탈락을 유발한다. III 의심이면 **관찰만**
5. **사진** — 차트 첨부용. 나중에 "원래 그랬는지" 논쟁을 막는 유일한 수단

**같은 근무 내 (30분~)**

6. **기도 위험 평가**: 발관/재삽관 예정? bite block·ETT 고정이 **그 치아 위에 물려 있나?** → 위치 재배치
7. **팀 공유 + 침상 표식** — 침상·차트·인계에 **"치아 고위험"** 플래그. *야간 응급 삽관하는 사람은 낮에 본 사람이 아니다*. 이 한 줄이 프로토콜의 실제 가치
8. **구강간호 차수 하향** — I → 2차 / II~III → 3차(스펀지+불소)
9. **의사 보고 & 치과 협진** — 고정(splinting) vs **계획적 발치** 판단. 통제된 상황에서의 발치가 응급 상황의 흡인보다 안전할 수 있다는 관점이 필요
10. **설명·기록** — 발견 시점, 등급, 조치, 보호자 설명

**하지 말 것 (명시적으로 넣을 것)**
- ❌ 실·거즈로 임의 고정 → **그 실이 곧 이물**
- ❌ "빠질 것 같으니 미리 빼보기" → 간호사가 판단·시행할 영역 아님
- ❌ 반복 동요도 검사
- ❌ 기록 없이 인계로만 전달

**추적**: 매 duty 동요도 재확인 → 등급 악화 시 차수 재하향 + 재보고

*(※ Miller 동요도 분류·splinting 적응증은 치과 영역 표준 분류를 인용한 것으로, 강의자료·병원 치과 지침과 대조 확인 필요)*
